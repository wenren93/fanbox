# 03 — 识别相同安装项与名称歧义

**What to build:** 让导入在写入前区分“目标已有完全相同安装项”和“目录名不同但 Skill 名称相同”。相同内容不重复落盘；名称歧义阻止导入并帮助用户定位冲突安装项。

**Blocked by:** 02 — 支持全部来源并守住文件边界

**Status:** ready-for-agent

- [ ] 内容比较覆盖相对路径、条目类型、普通文件字节内容和可执行权限，并忽略所有者、时间戳及扩展属性。
- [ ] 来源与目标的有效内容完全一致时返回稳定的无需处理状态，不写文件、不改变目标时间戳，也不产生废纸篓项目。
- [ ] 页面把无需处理状态显示为“{Agent} 已有相同安装项”，不弹覆盖确认。
- [ ] 目标没有同目录名安装项、但另一个目录的 Skill 名称与来源相同时，导入返回稳定的名称歧义状态且不创建目标目录。
- [ ] 名称歧义结果包含冲突安装项身份和位置；页面提供“在文件区显示”，不提供强制继续。
- [ ] 为同目录名但内容不同的目标生成稳定内容指纹和结构化内容冲突结果，暂不执行覆盖。
- [ ] 通过真实 HTTP 接口测试一致内容不写盘、权限差异被视为内容差异、名称歧义无副作用以及内容冲突指纹；前端行为测试不依赖中文文案判断状态。
