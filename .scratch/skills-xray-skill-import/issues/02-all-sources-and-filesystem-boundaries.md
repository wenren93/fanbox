# 02 — 支持全部来源并守住文件边界

**What to build:** 让用户可以从全局、项目级、已停用和插件提供的有效 Skill 安装项导入，同时把软链接和特殊文件限制在明确的安全边界内。安全的链接内容成为独立目标；不安全内容在写入前被拒绝并给出可行动提示。

**Blocked by:** 01 — 打通无冲突的单目标导入

**Status:** ready-for-agent

- [ ] 全局、项目级、已停用和 Claude 插件提供的有效 Skill 安装项均可作为来源，残留项仍不可导入。
- [ ] 项目级来源通过当前浏览目录在执行时重新发现，不依赖过期页面快照。
- [ ] 插件来源选择目标时以简短文案提示：目标安装项将独立存在，不再随插件更新或卸载。
- [ ] 顶层软链接来源被解析为真实 Skill 内容，目标顶层不是指向来源的软链接。
- [ ] 内部软链接仅在最终解析结果仍位于真实来源 Skill 根内时被展开为独立内容，导入结果不依赖来源目录。
- [ ] 指向来源外部的链接、循环链接、socket、设备文件和 FIFO 在任何目标写入前被拒绝。
- [ ] 不安全内容的响应使用稳定机器状态并指出第一个问题相对路径；页面展示简洁、可行动的提示。
- [ ] 来源内容、来源启停状态以及 Claude/Codex 配置在成功和失败场景下均保持不变。
- [ ] 通过真实 HTTP 接口测试各种来源、安全内部链接、外部链接、循环和可创建的特殊文件；前端行为测试覆盖插件提示与结构化错误映射。
