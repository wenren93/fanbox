# 01 — 打通无冲突的单目标导入

**What to build:** 让用户从一个普通有效 Skill 安装项的详情点击“导入到…”，选择 Claude、Codex、Agents 共享目录或 WorkBuddy，并把完整内容导入尚无同名安装项的目标。成功后 Skills 透视自动刷新，来源保持展开，用户得到简洁的成功反馈。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 有效非残留安装项的展开详情提供“导入到…”入口，残留项不提供入口。
- [ ] 目标选择器一次只允许选择一个目标，展示 Agent 名称和实际全局位置，并排除会落回来源同一目录的目标。
- [ ] 可选目标仅为 Claude、Codex、Agents 共享目录和 WorkBuddy；请求使用受控目标标识，任意路径、未知标识和自我导入均被拒绝且无副作用。
- [ ] 执行时强制刷新 Skills 清单并重新确认来源身份，不能借导入接口复制任意本机目录。
- [ ] 目标根不存在时可以创建；普通文件、嵌套目录、空目录、二进制资源和 Agent 专属普通配置文件均被完整复制。
- [ ] 普通文件保留可执行权限，不要求保留所有者、时间戳或 macOS 扩展属性。
- [ ] 导入使用同级临时内容与原子创建；临时内容不被扫描为安装项，成功或失败后均不残留。
- [ ] 来源安装项和启停状态保持不变；导入不写 Claude 或 Codex 启停配置，也不重启 Agent。
- [ ] 成功后重新扫描，来源详情与当前筛选保持不变，提示“已导入到 {Agent}；新会话可发现”。
- [ ] 通过隔离 HOME 的真实 HTTP 接口测试四种目标、来源校验、完整落盘、权限和无副作用失败；前端行为测试覆盖入口、选择器、请求及刷新反馈。
