# 03 — 安全安装简单文本 Skill 到 Codex

**What to build:** 打通最窄但完整的外部安装路径：用户从一个 skills.sh 条目发起“检查并安装”，FanBox 将公开 GitHub 来源固定到具体 commit，受限下载和检查一个仅包含普通文本文件的 Skill，在确认后原子安装到 Codex，并记录可复现的来源身份。

**Blocked by:** 01 — 发现页签与基础搜索

**Status:** ready-for-agent

- [ ] “检查并安装”只接受能解析为公开 GitHub 仓库的条目；非 GitHub、私有或无法解析的来源保持可查看但解释性阻止安装。
- [ ] 本机 Git 将仓库 HEAD 解析为完整 40 位 commit SHA；Git 缺失、失败或返回可变/非法版本时阻止安装，不影响继续发现。
- [ ] 只从 GitHub codeload 下载该 commit SHA 的归档，不使用 skills.sh 下载快照，也不接受客户端提供的任意归档 URL。
- [ ] 下载进入新建随机临时目录，压缩流达到 10 MiB 即停止；使用 macOS 系统 tar 解包，系统 tar 缺失时说明原因并阻止安装。
- [ ] 解包过程限制最多 25 MiB、1,000 个文件和单文件 10 MiB；超限、绝对路径、父目录穿越、软链接、硬链接、特殊文件和特殊权限均被阻止且不产生目标副作用。
- [ ] 本票只允许目录和普通 UTF-8 文本文件；脚本、带执行位文件和二进制内容先作为尚未支持的风险类型解释性阻止。
- [ ] 从固定归档中唯一匹配目标 SKILL.md；无候选、多个候选、无效 frontmatter、非法名称或名称与目录不一致均阻止安装，不猜测或自动修复。
- [ ] 基础确认展示名称、描述、公开仓库、作者、固定 commit 短哈希、Codex 目标、文件数、总大小和“检查通过”的客观结论，并提供完整文件列表与来源链接。
- [ ] 外部文本只按转义后的纯文本展示；不执行 Markdown HTML、不运行脚本、不安装依赖、不调用 Agent 分析内容。
- [ ] 最终写入进入现有 Skills 串行写边界，使用完整临时副本和原子换位；安装成功前不会出现半个 Skill 安装项。
- [ ] 成功后在 FanBox 自有状态中原子记录仓库、Skill 子目录、commit SHA 和内容哈希，不修改 Skill 内容。
- [ ] 成功后切回“已安装”，刷新并展开新 Codex Skill 安装项，提示新会话可发现且 Codex 可能需要重启；不自动重启。
- [ ] 任一步失败都会清理下载、解包和暂存内容，保留结构化错误供重试，并确保 Codex 目标目录和来源记录没有残留。
- [ ] 集成测试通过真实本地服务、隔离 HOME、固定假 GitHub 来源与归档验证完整 HTTP 流程、落盘、扫描结果和失败无副作用。
