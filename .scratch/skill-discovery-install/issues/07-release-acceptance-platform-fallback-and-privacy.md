# 07 — 发布前验收、平台降级与隐私说明

**What to build:** 把 Skill 发现与安全安装收口为可发布能力：平台和系统工具限制对用户透明，所有对外网络行为有文档说明，关键浏览器流程可真实验收，现有 Skills 管理能力没有回归。

**Blocked by:** 02 — 搜索缓存与失败降级；06 — 异源冲突、未知安装项与原子恢复

**Status:** ready-for-agent

- [ ] 外部安装仅在 macOS 开放，并固定使用已验证的系统 tar；Windows 和 Linux 仍可“发现”和“打开来源”，安装按钮解释当前平台限制。
- [ ] macOS 缺少可用 Git 或系统 tar 时，“发现”和本机管理保持可用，安装入口说明缺失条件且不尝试不安全替代方案。
- [ ] README 和隐私说明明确列出 skills.sh 搜索、Git 远端解析和 GitHub codeload 下载，以及每个请求发送的数据。
- [ ] 产品不新增遥测，不记录搜索历史日志；只保存最近查询缓存、默认目标 Agent 和安装来源记录。
- [ ] 所有第三方审计入口、徽章、评分或“安全认证”措辞均不存在；风险结果只使用“检查通过”“需要确认”或结构性阻止。
- [ ] 真实浏览器验收完成完整主路径：进入 Skills 透视、切到“发现”、提交中文查询、开始“检查并安装”、查看固定来源与风险、选择目标、确认安装、返回“已安装”并看到新安装项展开。
- [ ] 浏览器验收覆盖空结果、外部失败、缓存结果禁用安装、加强确认、用户取消、安装失败保留上下文和成功后的筛选保持。
- [ ] 服务级验收覆盖四个目标、固定 commit、归档限额、危险文件、同源更新、异源冲突、本地修改、并发变化、原子回滚和卸载来源记录。
- [ ] 现有 Skills 扫描、搜索、筛选、导入、启停、卸载和批量管理测试全部通过，不因“发现”依赖外部网络。
- [ ] 外部服务超时、限流、格式变化或不可达不会延迟或破坏“已安装”页、本地 Skills API和现有 Agent 工作流。
- [ ] 原型确认的方案 A 被落实为顶层“已安装 / 发现”双页签；原型文件不作为生产实现发布。
- [ ] 发布说明准确写明首版不支持私有仓库、非 GitHub 安装、任意 URL、项目级目标、Windows/Linux 安装、自动更新、依赖安装或第三方审计。
