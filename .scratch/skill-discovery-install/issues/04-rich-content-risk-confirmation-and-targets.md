# 04 — 丰富内容、风险确认与四个目标 Agent

**What to build:** 在已验证的简单文本安装路径上支持真实世界的复杂 Skill：普通二进制资源和经过规范化的脚本可以保留，许可证、工具与依赖在确认前可见；用户可安装到四个受控目标 Agent，并记住应用级默认目标。

**Blocked by:** 03 — 安全安装简单文本 Skill 到 Codex

**Status:** ready-for-agent

- [ ] 图片、字体、PDF 等普通不可执行二进制资源通过风险检查并被完整保留，仍受总量、数量和单文件限额约束。
- [ ] 未知可执行二进制继续硬阻止；软链接、硬链接、特殊文件和特殊权限仍不可绕过。
- [ ] 来源中任一执行位存在的允许脚本在目标中规范化为 0755；普通文件为 0644，目录为 0755；不保留 SUID、SGID、sticky、ACL、扩展属性、所有者或系统标志。
- [ ] 风险检查列出脚本、可执行文件、二进制资源、声明工具、外部依赖和文件清单，但不会执行其中任何内容。
- [ ] 许可证优先取 Skill frontmatter 或 Skill 目录内明确许可证；只有范围明确时才采用仓库许可证，否则显示“许可证未知”。
- [ ] 无脚本、无高权限工具且许可证明确的 Skill 使用普通确认；存在脚本、高权限工具、未知许可证或其他未知风险时自动展开风险明细并要求勾选确认。
- [ ] 加强确认不要求输入 Skill 名称；未勾选风险确认时安装按钮不可用。
- [ ] 安装确认允许选择 Claude、Codex、Agents 或 WorkBuddy，并且客户端只提交受控目标标识，服务端不接受任意路径。
- [ ] 用户可记住一个应用级默认目标；以后确认页默认选中该目标但始终允许更改。
- [ ] 受控目标根不存在时，仅在用户确认安装后创建；创建失败不会留下来源记录或半个安装项。
- [ ] 四个目标均安装到正常启用目录，不调用启停接口、不改变既有启停配置，也不自动重启 Agent。
- [ ] 每个目标的成功反馈准确说明新会话生效和必要的重启预期，并在“已安装”中定位新的安装项。
- [ ] 测试覆盖普通二进制、允许脚本、未知可执行二进制、许可证范围、普通/加强确认、默认目标以及四个受控目标的成功安装。
