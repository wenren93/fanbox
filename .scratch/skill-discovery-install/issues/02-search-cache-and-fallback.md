# 02 — 搜索缓存与失败降级

**What to build:** 让“发现”在网络不稳定或上游变化时仍然可理解：重复查询减少请求，最近一次成功结果可以短期离线查看，但用户不会把过期展示数据误认为可安全安装的来源。

**Blocked by:** 01 — 发现页签与基础搜索

**Status:** ready-for-agent

- [ ] 相同规范化查询在成功后的 10 分钟内直接复用，不重复访问 skills.sh。
- [ ] 本地只持久化最近一次成功查询及最多 20 条规范化结果，缓存保留 24 小时，不形成搜索历史列表。
- [ ] 上游不可用但存在未过期缓存时，继续展示结果并标明缓存时间和离线/降级状态。
- [ ] 缓存结果的“检查并安装”处于禁用状态；只有重新联网并重新验证来源后才可进入安装流程。
- [ ] 无缓存时，超时、限流、离线、非成功 HTTP 状态和响应格式变化分别归为外部搜索失败，不显示为“没有找到”。
- [ ] 过期缓存不继续展示为当前结果，并按隐私约定清理或替换。
- [ ] 持久化缓存不包含本机 Skill 清单、目标 Agent、安装记录、项目路径或额外遥测信息。
- [ ] 测试通过可控时间和假上游验证 10 分钟复用、24 小时保留、缓存降级、过期清理及安装禁用。
